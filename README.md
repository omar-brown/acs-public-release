## What ACS Is

ACS is a governed cognition runtime. It addresses a core limitation in current AI systems: they can retrieve information but lack disciplined mechanisms to determine what context should actually matter for a given decision.
The central idea is governed relevance — the process of selecting, labeling, scoping, and validating context so that AI guidance maintains continuity without being overwhelmed by noise or treating inference as settled fact.
